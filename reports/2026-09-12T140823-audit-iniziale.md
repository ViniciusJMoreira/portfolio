## Executive Summary

Il sito (Next.js 16, App Router) ha le basi pulite: title/description per pagina, un solo H1 a pagina, `<html lang="it">`, tutte le immagini via `next/image` (niente `<img>` grezzi). Mancano però tre elementi fondamentali per l'indicizzazione — **robots.txt, sitemap.xml, canonical tag** — nessuno dei tre è presente in nessuna forma nel codice. Sono gap "silenziosi": il sito continua a funzionare e a "sembrare" pulito, ma senza questi Google fatica a scoprire e preferire le URL corrette, specialmente ora che il blog inizierà a pubblicare più articoli. Mancano anche Open Graph e structured data (JSON-LD) per gli articoli — impattano le anteprime social (rilevante visto che il CTA principale del sito è LinkedIn) e la comprensione dei contenuti da parte di Google.

## Findings by Severity

### High (3 findings)

| Rule | Source | Location | Description |
|------|--------|----------|--------------|
| ROBOTS-001 | Code | (assente) | Nessun `robots.txt` né `app/robots.js` — Google non ha indicazioni esplicite su cosa crawlare, e non c'è un punto da cui referenziare la sitemap |
| SITEMAP-001 | Code | (assente) | Nessun `sitemap.xml` né `app/sitemap.js` — Google deve scoprire le pagine solo seguendo i link, più lento e meno affidabile (specialmente per nuovi articoli del blog) |
| CANONICAL-001 | Code | `src/app/layout.jsx`, tutte le pagine | Nessun tag/`metadata.alternates.canonical` in nessuna pagina — rischio di contenuto duplicato percepito da Google (es. con/senza trailing slash, http/https) |

### Medium (3 findings)

| Rule | Source | Location | Description |
|------|--------|----------|--------------|
| META-003 | Code | `src/app/layout.jsx` (metadata globale) | Nessun `openGraph` configurato — le anteprime quando condividi il sito o un articolo su LinkedIn/WhatsApp mostrano un box vuoto/generico |
| SCHEMA-001 | Code | `src/app/blog/[slug]/page.jsx`, `src/app/page.jsx` | Nessun JSON-LD. Gli articoli del blog beneficerebbero di `BlogPosting` (autore, data — già li avete nel JSON!), la home di `Person`/`WebSite` |
| IMAGES-001 | Code | `src/app/about/page.jsx:79` | Il ritratto principale (`portraitImage`) ha `alt=""` — è un'immagine di contenuto (la tua foto), non decorativa: merita un alt descrittivo (es. "Ritratto di Vinícius Junqueira Moreira") |

### Low (2 findings)

| Rule | Source | Location | Description |
|------|--------|----------|--------------|
| META-004 | Code | `src/app/layout.jsx` | Nessun `twitter:card` — fallback minore rispetto a OG, ma facile da aggiungere insieme |
| ENV-RISK | Code | `.env.example` vs assenza `.env.local` | `NEXT_PUBLIC_SITE_URL` non risulta impostato in locale. `feed.xml` già lancia un errore esplicito se manca — se non è impostato anche su Vercel in produzione, RSS feed e (una volta aggiunti) OG/canonical assoluti si romperebbero silenziosamente.
